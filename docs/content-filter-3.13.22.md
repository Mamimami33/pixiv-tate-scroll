# v3.13.22 コンテンツフィルタ

基準: main `4d04d45`。表示モード `viewMode`、取得経路 `mode` (custom/search)、
コンテンツ条件 `contentFilter` は独立して保持する。

## 操作と保存

- フルページ読み込みごとに下部の選択シートを表示。アカウント識別完了後に
  `PTS_CONTENT_FILTER_V1:<pixivUserId>` を読み、未識別の場合のみ `guest` を使用。
- 前回値を選択済みにし、1タップで開始。ドック先頭の現在値から変更できる。
- 「すべてに戻す」は下書きだけを変更し、確定で保存・再生成。キャンセル/Escapeは保存しない。
- 条件変更は先頭から再生成し、検索グリッドを表示中なら同じ検索語で作り直す。
  旧グリッド復帰状態・閲覧履歴・シリーズ画面は破棄する。
- v3.13.21 の明示的な閉じる操作による自動起動抑止は維持する。

## 判定・経路

`illustType` と `xRestrict` は既知の 0/1/2 のみ有効。
欠落、null、空文字、boolean、不正値を0に変換しない。
「すべて」でも不明メタデータは表示しない。マンガは種別1のみ、
イラスト・うごイラは0/2、全年齢は年齢0、R-18は年齢1のみ。
R-18G (2) は年齢「すべて」でのみ通す。

一覧APIの値を正規化し、必要な候補だけ詳細取得する。既知の不一致候補には
詳細照会しない。1回の候補準備で最大24件、同時4件、1照会5秒で打ち切る。
メタデータキャッシュは最大500件。既存のタグ/ブックマーク状態の補完は別枠
（通常最大24件、ブックマーク差し込み16件）だが、その後も再判定する。

通常・検索フィードとグリッドは共通候補準備段階で判定してから順位付けする。
スライド挿入、グリッドカード挿入・作品を開く操作、履歴移動でも再確認する。
シリーズ次話差し込みは詳細応答、シリーズ一覧は各ページのメタデータを検証して
サムネイル表示前に遮断し、専用読者も詳細応答を検証してから画像を読む。

条件変更はフィルタ世代・フィード世代・検索プール・グリッドトークン・
シリーズ読者トークンを失効させる。非同期結果は世代検証後だけ反映する。
フィルタ非依存の作品メタデータキャッシュは共有してよいが、利用時に現在条件で判定する。

フィルタ変更では閲覧終了/スキップ学習を呼ばず、選択シート表示中は閲覧時間の
加算を止める。検索の tier、tasteScore、比較関数、同点処理は変更しない。

## 取得元連動と制約

- 選択に合うブックマーク履歴を推薦シードに使用。現在作品をシードにする場合も検証する。
- discovery に `mode=all/safe/r18`、`type=all/manga/illust_and_ugoira` を渡す。
- タグ検索にも同じ種別・年齢条件を渡し、追加取得ではページを進める。
  follow_latest は年齢条件を渡す。マンガ選択時は既存のイラスト用作者APIを使わない。
- ブックマーク関連は元作品の推薦APIと条件付きdiscoveryを併用。
  年齢・種別が「すべて」の軸は元作品から取得条件を補い、通常フィードの
  差し込みでは同種・同区分を優先する。
- 検索のブックマーク差し込みは検索APIヒット資格と既存順位を維持するため、
  現在選択の取得条件を使用し、種別/年齢による独自の順位加点は追加しない。
- 元作品推薦、推薦nextIdsのAPIには確認済みの種別/年齢専用パラメータがないため、
  シードの選択と返却候補のクライアント検証で対応する。
- API側の条件適用は最終保証に使わない。pixivがパラメータを無視・拒否する場合や
  アカウント設定で返さない場合は候補が減る。今回の検証はAPI応答を模した
  Chromiumテストであり、ログイン済み実アカウントでのサーバー側絞り込みは未検証。
  pixivの閲覧設定を変更したり、制限を回避する通信は行わない。

通常フィードの初回は最大3バッチ。追加取得でも3回連続の空バッチで自動取得を止める。
検索は既存の1回最大3ページ、初回最大3回（グリッドは2回）という上限を維持する。
0件画面には原因を断定しない説明、条件変更、明示的な追加取得ボタンを表示する。
取得予算内で見つからない場合も条件を緩めない。

## 検証

```sh
node --check pixiv-tate-scroll.user.js
git diff --check
node tests/content-filter.cjs
```

ブラウザテストには Playwright と Chromium が必要。
`CHROMIUM_PATH` で実行ファイルを指定できる（既定 `/usr/bin/chromium`）。
